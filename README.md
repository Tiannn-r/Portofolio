# Portofolio

Website Portofolio Pribadi & Admin CMS.

## Tech Stack
- **Backend**: Laravel 11 (REST API, Sanctum Authentication)
- **Database**: MySQL
- **Frontend**: Vue 3 (Composition API) + Tailwind CSS

## Fitur Utama
1. **Profiles**: Biodata diri, role typing effect, file CV, statistik, kontak & social links.
2. **Skills**: Technical skills (grid icon) dan My skills (progress bar).
3. **Services**: Layanan yang disediakan beserta ikon dan deskripsi.
4. **Projects**: Showcase proyek dengan filter kategori, tags teknologi, slider featured projects, demo URL & repository URL.
5. **Educations & Certifications**: Riwayat pendidikan dan sertifikasi resmi.
6. **Contact Messages**: Form pesan kontak publik dengan panel kelola pesan di CMS Admin.
